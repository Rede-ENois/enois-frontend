# Énois · Brand Assets Kit

**Conceito escolhido:** o segundo rebranding, um **joinha-personagem** que também lembra um balão de conversa, com olhos e sorriso. Paleta roxa/lilás, com pequenos acentos coral.

**Slogan oficial:** “Você não se adapta à plataforma, a plataforma se adapta a você.”

## Organização

| Pasta              | O que inclui                                                        |
| ------------------ | ------------------------------------------------------------------- |
| `01-brand/svg/`    | Símbolo vetorial (principal, flat, claro, escuro) e lockups         |
| `01-brand/png/`    | Exports transparentes em múltiplas resoluções                       |
| `02-web/`          | favicon.ico, favicon.svg, web icons, apple-touch-icon, manifest PWA |
| `03-app/ios/`      | AppIcon 1024 × 1024                                                 |
| `03-app/android/`  | launcher icons por densidade + round icons                          |
| `03-app/adaptive/` | camadas para adaptive icon Android                                  |
| `04-social/`       | Card OG 1200 × 630 e post quadrado 1080 × 1080                      |
| `05-tokens/`       | CSS custom properties e JSON de cores                               |
| `06-examples/`     | Exemplo pronto de tags `<head>` e instalação                        |
| `07-preview/`      | Prancha visual de conferência                                       |
| `08-reference/`    | Imagem do conceito visual original (somente referência)             |

## Antes de subir em produção

Este pacote contém uma **reconstrução vetorial aproximada**, desenhada para preservar a essência do conceito gerado por IA. Os arquivos SVG são escaláveis e editáveis, mas **não são um trace 100% fiel do board**. Revise proporções/legibilidade, especialmente em 16 px. Nenhuma fonte de terceiros é redistribuída: as letras do wordmark foram convertidas em caminhos vetoriais.

Use sempre a variante monocromática sobre fundos complexos e faça testes em dark e light mode.
